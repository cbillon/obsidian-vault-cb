# Mistral AI Provider for Moodle

[](https://github.com/fondation-unit/moodle-aiprovider_mistral#mistral-ai-provider-for-moodle)

A Moodle AI provider plugin that integrates [Mistral AI](https://mistral.ai/) into Moodle's AI subsystem, enabling text generation, text summarisation, text explanation, and image generation.

## Features

[](https://github.com/fondation-unit/moodle-aiprovider_mistral#features)

- Text generation
- Text summarisation
- Text explanation
- Image generation
