#Installation sur Chrome OS

[video](https://www.youtube.com/watch?v=ZoAaTsOy3Qo)
Télécharger
wget github.com/obsidianmd/obsidia-releases/releases/download/v1.9.14/obsidian_1.9.14_amd64.deb

sudo dpkg -i obsidian_1.9.14_amd64.deb
